# Puerto Colibrí noticeboard copy

The sign in the zócalo reads **Frase del día**. When a posting is missing, the sign reads **Hoy no hay frase en el tablero.** Both courses post the same Mexican Spanish sentence. The sheet, buttons, and Cards source use the active learner’s language.

| Use | English layer | Lithuanian layer |
| --- | --- | --- |
| Sheet heading | Phrase of the day | Dienos frazė |
| Read prompt and touch button name | Read today’s phrase | Skaityti dienos frazę |
| Short touch button | Read | Skaityti |
| Date, shown in the learner’s local calendar | November 26, 2026 | 2026 m. lapkričio 26 d. |
| Visible speaker codes, target then helper | ES / EN | ES / LT |
| Target speaker tooltip | Hear the phrase | Klausytis frazės |
